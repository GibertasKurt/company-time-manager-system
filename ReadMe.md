# Company Time Manager System
## Overview
The Company Time Manager System is a complete web-based application that is programmed to handle these needs efficiently. It is programmed using HTML, JavaScript, Go, and Uadmin and provides a sound and adaptable solution that is capable of handling the different needs of different organizations.

The benefits of implementation of the Company Time Manager System are considerable. With automated tracking of time and attendance, organizations can save considerable administrative effort and enhance operations. The system reduces errors in time monitoring, and employees' work hours are accurately recorded and reported. Secondly, employees are better informed and in command of their schedules of work, leading to enhanced satisfaction and engagement.
## Features
- Working registration and login system
- Optional Break Time feature
- Employee time tracking
- Responsive design for mobile and desktop
- Admins can see all employees' time records
## Installation
Requirements:
- [Go language installed](https://go.dev/doc/install)
- [Uadmin installed](https://github.com/uadmin/uadmin?tab=readme-ov-file#installation)

Clone the repository
```bash
git clone https://github.com/kurt/company-time-manager-system.git
```
Change directory to the project folder
```bash
cd company-time-manager-system
```
Build and run it
```bash
go build; ./company-time-manager-system
```
## Usage
When making changes to the code, specifically amy go files, you have to use the following command to build and run the application:
```bash
go build; ./company-time-manager-system
```
There is no need to run this when making changes to HTML, CSS, or JavaScript files. It only requires the user to perform a hard refresh (via CTRL+F5 or CTRL+SHIFT+F5) on the website to make the application take these changes.
